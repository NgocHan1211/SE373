# Nộp bài — Block 1

Gói này gồm mã nguồn đăng ký và triển khai tool cho Stage 01/02, hai chính sách, skill `refund-policy/`, `analysis.md` và các trace được dẫn trong phân tích.

- Trace đổi tên sai ban đầu được giữ lại để đối chiếu; trace chạy lại đúng cũng có trong gói.
- Không bao gồm `.env`, API key, `.venv`, cache hay log debug.
- Mở `analysis.md` để xem kết quả từng trường hợp, mốc bằng chứng trong trace và câu trả lời cuối bài.
